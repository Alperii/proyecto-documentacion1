# Servidores

## ¿Qué es un servidor web?
Un programa que recibe peticiones HTTP y devuelve respuestas.

## Servidores populares
- **Apache**
- **Nginx**
- **Node.js** (Express)

## Conceptos clave
- Puertos (80 HTTP, 443 HTTPS)
- Proxy inverso
- Balanceo de carga

Más info: [Nginx](https://nginx.org/) · [Express](https://expressjs.com/)
