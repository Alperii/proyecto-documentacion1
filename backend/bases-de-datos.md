# Bases de datos

## Relacionales (SQL)
- MySQL, PostgreSQL
- Datos en tablas con relaciones

```sql
SELECT nombre FROM usuarios WHERE activo = 1;
```

## No relacionales (NoSQL)
- MongoDB (documentos)
- Redis (clave-valor)

## Conceptos clave
- Claves primarias y foráneas
- Índices
- Transacciones
