# APIs REST

## ¿Qué es una API REST?
Una interfaz que permite comunicar aplicaciones mediante HTTP.

## Métodos HTTP
| Método | Acción |
|--------|--------|
| GET | Leer |
| POST | Crear |
| PUT | Actualizar |
| DELETE | Borrar |

## Códigos de estado
- 200 OK
- 201 Creado
- 404 No encontrado
- 500 Error del servidor

## Ejemplo
`GET /api/usuarios/1`

Más info: [MDN HTTP](https://developer.mozilla.org/es/docs/Web/HTTP)
