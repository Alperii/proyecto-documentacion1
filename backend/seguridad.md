# Seguridad web

## Amenazas comunes
- **Inyección SQL**
- **XSS** (Cross-Site Scripting)
- **CSRF**

## Buenas prácticas
- Usar HTTPS
- Validar y sanear datos de entrada
- Guardar contraseñas con hash (bcrypt)
- Mantener dependencias actualizadas

## Autenticación
- Sesiones
- Tokens JWT

Más info: [OWASP](https://owasp.org/)
