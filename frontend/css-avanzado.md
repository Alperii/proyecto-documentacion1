# CSS avanzado
## Layouts modernos
- **Flexbox:** distribución en una dimensión.
- **Grid:** distribución en dos dimensiones.

## Variables CSS
```css
:root { --color-principal: #3498db; }
a { color: var(--color-principal); }
```

## Diseño responsive
- Media queries
- Unidades relativas (`rem`, `%`, `vw`)

## Animaciones
- `transition`
- `@keyframes`
