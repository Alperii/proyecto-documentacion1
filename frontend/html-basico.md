# HTML básico

## ¿Qué es HTML?
HTML (HyperText Markup Language) define la **estructura** de una página web.

## Estructura mínima
```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi página</title>
  </head>
  <body>
    <h1>Hola mundo</h1>
  </body>
</html>
```

## Etiquetas comunes
- `<h1>` a `<h6>`: títulos
- `<p>`: párrafos
- `<a>`: enlaces
- `<img>`: imágenes
- `<ul>` y `<li>`: listas

Más info: [MDN HTML](https://developer.mozilla.org/es/docs/Web/HTML)
