# JavaScript moderno (ES6+)

## Novedades principales
- `let` y `const` en lugar de `var`
- Funciones flecha
- Plantillas de texto
- Desestructuración
- Módulos (`import` / `export`)

## Ejemplo
```javascript
const saludar = (nombre) => `Hola, ${nombre}`;
console.log(saludar("Mundo"));
```

## Asincronía
- Promesas
- `async` / `await`
- `fetch` para llamadas HTTP

Más info: [MDN JavaScript](https://developer.mozilla.org/es/docs/Web/JavaScript)
