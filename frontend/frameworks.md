# Frameworks frontend

## ¿Por qué usarlos?
Aceleran el desarrollo, organizan el código y facilitan reutilizar componentes.

## Principales
| Framework | Creador | Enfoque |
|-----------|---------|---------|
| React | Meta | Librería de componentes |
| Vue | Comunidad | Progresivo y sencillo |
| Angular | Google | Framework completo |

## Cómo elegir
- Tamaño del proyecto
- Experiencia del equipo
- Ecosistema y comunidad

Más info: [React](https://react.dev/) · [Vue](https://vuejs.org/) · [Angular](https://angular.dev/)
