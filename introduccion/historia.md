# Historia del desarrollo web

## Los orígenes (1989-1995)
- En 1989 **Tim Berners-Lee** propone la World Wide Web en el CERN.
- En 1993 aparece el navegador Mosaic.
- En 1995 nace JavaScript.

## La web dinámica (2000-2010)
- Aparecen PHP, ASP y los primeros CMS.
- AJAX permite actualizar páginas sin recargarlas.
- Se populariza CSS para separar contenido y diseño.

## La web moderna (2010-actualidad)
- HTML5 y CSS3 se consolidan.
- Surgen frameworks como Angular, React y Vue.
- El diseño responsive se vuelve estándar.
