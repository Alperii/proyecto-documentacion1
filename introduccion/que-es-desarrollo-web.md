# ¿Qué es el desarrollo web?

## Definición
El desarrollo web es el proceso de **crear sitios y aplicaciones** que funcionan en un navegador a través de Internet.

## Áreas principales
- **Frontend:** lo que ve y usa el usuario.
- **Backend:** la lógica y los datos en el servidor.
- **Fullstack:** combina ambas áreas.

## Cómo funciona una web
1. El usuario escribe una URL en el navegador.
2. El navegador envía una petición al servidor.
3. El servidor responde con HTML, CSS y JavaScript.
4. El navegador muestra la página.
